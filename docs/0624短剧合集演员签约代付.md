已将三条 mint 链路的邮箱用户统一改为后端 sponsor API，不再走 Privy `signAndSendTransaction` / Privy 侧 gas sponsorship。

## 架构变更

| 场景 | 邮箱用户（embedded） | 外链钱包 |
|------|---------------------|----------|
| 演员合集创建 | `useSponsorCreateActorCollection` → signMessage → sponsor API | `useCreateActorCollectionOnChain` → signAndSendTransaction |
| 演员签约 mint | `useSponsorMintActorNft` | `useMintActorNftOnChain` |
| 短剧 mint | `useSponsorMintDramaNft` | `useMintDramaNftOnChain` |

## 新增 / 调整的文件

**共享 sponsor 基础设施（`src/hooks/sponsor/`）**
- `useSponsorMintConfig.ts` — 代付配置（sponsorUrl、spender、钱包）
- `buildSponsorCoreMintPrepInstructions.ts` — rent 预转 + creator USDC ATA 幂等创建
- `sponsorSubmitResult.ts` — 增加 `submitSponsorTransaction`、`getSponsorSubmitErrorMessage`

**各业务代付 hook**
- `actorCollection/useSponsorCreateActorCollection.ts` — **新增**
- `actorMint/useSponsorMintActorNft.ts` — 重构，复用共享工具
- `dramaMint/useSponsorMintDramaNft.ts` — 重构，补上 prep 指令

**UI 分叉**
- `CreateActorForm.tsx` — 按 `isEmbeddedLogin` 选择 sponsor / 直连

**直连 hook 限制（仅外链钱包）**
- `useCreateActorCollectionOnChain.ts`
- `useMintActorNftOnChain.ts`
- `useMintDramaNftOnChain.ts`

## 删除的无效文件

- `src/hooks/solana/actorMint/buildSponsorBatchMintActorNftPrepInstructions.ts`（逻辑迁入 `buildSponsorCoreMintPrepInstructions.ts`）
- `src/hooks/sponsor/dramaMint/submitMintDramaSponsorRequest.ts`（旧协议未使用；`getSponsorSubmitErrorMessage` 迁入 `sponsorSubmitResult.ts`）

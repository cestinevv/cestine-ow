# 演员 IP 徽章与详情价格 UI 设计

## 目标

根据 Figma 调整演员列表卡片、演员详情主页、参演短剧、演员 IP 金库及价格说明弹窗。使用生成 API 的 `badge`、`assetId`、`creatorName` 字段展示真实数据，同时保持现有价格、签约、售罄和跳转逻辑不变。

## 数据映射

- `badge`：控制封面左上角徽章；字段缺失时不展示。
- `assetId`：展示为封面底部左侧的演员 IP 编号，不使用演员集合 `id` 代替。
- `creatorName`：展示为封面底部右侧的创作者名称；字段缺失时展示 `-`。

徽章枚举文案：

- `OFFICIAL`：官方发行
- `COMMUNITY`：社区发行
- `PARTNER`：合作方发行
- `VERIFIED`：认证创作者发行

## 组件设计

新增演员/短剧可复用的徽章展示组件，负责：

- 接收后端徽章枚举值。
- 映射中文 i18n 文案。
- 映射图标与视觉风格。
- 未知值或空值时不渲染。

演员列表卡片负责：

- 在封面左上角渲染徽章组件。
- 在封面底部左侧渲染 IP 图标与 `assetId`。
- 在封面底部右侧渲染用户图标与 `creatorName`。
- 删除原封面顶部发行者标签。
- 保持正文信息、价格弹窗、签约弹窗及按钮逻辑不变。

演员详情主页负责：

- 在演员名称后展示演员集合 `badge`。
- 在参演短剧卡片封面展示短剧 `badge`。
- 发行信息保持合约地址、Token 标准、定价类型、总发行量、已签约、剩余六项。
- 曲线价格展示公式、曲线图、初始价格、当前价格、尾价。
- 固定价格不展示曲线图，展示固定价格模式对应的信息布局。
- 新增演员 IP 金库区块与说明弹窗。

价格说明弹窗负责：

- 曲线价格弹窗展示风险说明、公式、价格曲线、当前位置，以及价格和发行数量统计。
- 固定价格弹窗使用独立说明内容和统计布局，不展示曲线图。
- 弹窗继续复用 `AppDialog`，只调整 DOM 与样式，不改变打开、关闭和业务数据逻辑。

## 视觉规则

- 卡片封面维持 `6 / 5` 比例。
- 徽章使用紧凑胶囊样式，位置为封面左上角 `12px`。
- IP 和创作者使用半透明黑色胶囊，位置为封面底部两侧。
- 文字单行截断，避免长创作者名称覆盖 IP 编号。
- 移动端和桌面端使用同一卡片结构，不新增额外断点。
- 优先复用项目图标库；若 Figma 徽章图标无现成实现，再增加语义化本地 SVG 组件。
- 详情页桌面端忠实还原 `6217:52217`、`6279:65960` 和 `6284:72378`；移动端沿用现有移动优先结构。
- 金库金额暂无接口时展示 `-- USDC`，不编造业务数据。
- 金库说明使用 `6284:72912` 文案和单按钮确认弹窗。

## 状态与兼容

- `badge` 缺失：不显示徽章，不显示空占位。
- `assetId` 缺失：显示 `-`，不回退到可能含义不同的集合 `id`。
- `creatorName` 缺失：显示 `-`。
- 未识别的徽章枚举：不展示，避免向用户显示后端代码值。
- 金库数据缺失：展示明确占位，不回退为 `0`。
- 曲线和固定价格根据 `pricingMode` 分支渲染，旧数据缺失模式时沿用现有曲线模式兼容逻辑。

## 验证范围

- 检查四种徽章文案映射。
- 检查无徽章、无 `assetId`、无 `creatorName` 的降级展示。
- 检查长创作者名称截断及卡片封面元素不重叠。
- 检查卡片跳转、价格弹窗和签约按钮原有交互未改变。
- 检查详情名称及参演短剧徽章与接口枚举一致。
- 检查曲线模式和固定模式详情内容互斥。
- 检查金库数据缺失时不出现虚构金额。
- 普通实现阶段不运行 `tsc`、`biome check`、`git diff --check` 或全量类型检查。
